# 小狼毫扩展工具箱

一个面向 Windows 小狼毫（Weasel）的本地管理工具，用于添加常用词、维护快捷短语、按输入方案写入固定短语表，并在每次部署前自动创建可恢复备份。

> 当前版本为 **0.4.1 未测试版（预发布）**。已通过自动化回归及便携包启动检查，但尚未完成真实输入法全面试输、真实断电及多环境验收，不建议直接用于重要数据。使用前请备份并阅读“已知限制”。

## 主要功能

- 自动识别小狼毫安装目录、用户目录和当前启用的输入方案。
- 添加、修改、删除常用词和快捷短语。
- 同编码快捷短语自动使用现有最大排序值加一，也可手动调整。
- 所有变更先保存为待同步内容，由用户明确点击“写入词库”后才部署。
- 写入前自动备份工具管理的配置和短语表，失败时尽量回滚。
- 默认保留最近 20 份写入备份和 5 份恢复安全备份；重要备份可长期保留。
- 中文操作记录支持折叠详情，并可导出脱敏诊断信息。
- 数据只保存在本机，不提供云同步或遥测上传。

## 系统要求

- Windows 10 或 Windows 11
- 已安装小狼毫输入法
- Node.js 22.12 或更高版本
- pnpm 11（项目声明版本为 11.19.0）

本项目目前仅针对小狼毫进行设计，不支持 macOS 鼠须管或 Linux 中州韵前端。

## 安装与运行

### 普通用户：免安装便携版

1. 从 [v0.4.1 未测试版](https://github.com/zwubaili/weasel-toolbox/releases/tag/v0.4.1) 下载 `WeaselToolbox-Portable-v0.4.1-win-x64.zip` 及校验文件。
2. 将整个 ZIP 解压到可写入的普通文件夹，不要直接在压缩包内运行。
3. 双击 `WeaselToolbox.exe`。
4. 工具会打开默认浏览器；退出时右键系统托盘图标并选择“退出”。

便携版已经内置 Node.js，不需要另外安装 Node.js 或 pnpm。当前程序没有代码签名，Windows SmartScreen 可能显示“未知发布者”。

### 开发者：从源码运行

```powershell
git clone https://github.com/zwubaili/weasel-toolbox.git
cd weasel-toolbox
pnpm install --frozen-lockfile
pnpm test
pnpm start
```

启动成功后，在浏览器打开：

```text
http://127.0.0.1:43187/
```

本地服务只监听 `127.0.0.1`。程序启动时会生成临时访问令牌，并检查 Host、Origin 和请求令牌；不要把服务改为公网监听。

## 使用方法

### 添加内容

常用词和快捷短语列表支持全量搜索、状态筛选，以及最近修改、最早添加、编码 A–Z/Z–A 排序；每页50条。编码相同时按候选排序显示，列表排序不会修改输入法候选顺序。快捷短语可展开完整内容，待删除记录单独计数。

1. 打开“常用词”或“快捷短语”。
2. 输入编码与内容。
3. 勾选需要生效的输入方案；默认不勾选任何方案，避免误写。
4. 保存后，记录会以渐紫色显示为待同步状态。
5. 检查无误后点击页面顶部“写入词库”。
6. 切换到对应输入方案进行实际试输确认。

保存草稿不等于已经写入小狼毫。修改或删除已部署内容后，也需要再次点击“写入词库”才会生效。

### 备份与恢复

- 每次写入前都会备份完整本地记录及工具管理的文件。恢复后记录标记为待同步，以免把历史待修改记录误认为已经生效。
- 恢复旧备份前还会创建一份当前状态的安全备份。
- 写入备份保留最近 20 份，恢复安全备份保留最近 5 份。
- 标记为“长期保留”的备份不会被自动清理。
- 可以查看每份备份大小、恢复备份或手动删除。
- 旧版备份只有配置，界面会明确标注；新备份同时包含本地记录。不包含 Rime 活跃学习数据库。

### 记录导入、导出与找回

- 本地记录总量上限10000条，含待删除项；超限时不继续新增或合并，请先同步删除或减少导入数量。
- “本地记录快照”提供直接恢复入口，区别于导入合并：它会替换本地记录，移除快照之后的新增项，并先保存当前状态以便再次恢复。不会立即改动输入法，之后需要检查并同步。
- 有效自动记录快照保留最近20份，本次恢复来源与安全副本额外保护；仅在合并或恢复成功后清理。损坏快照留待人工处理，手动导出文件不自动删除。
- 新快照有内容校验；旧快照只能做结构校验，页面会标注。恢复期间修改被阻止，本地数据替换使用SQLite事务。

- “导出全部记录”将常用词和快捷短语保存到同一个 JSON，保留分类；分类页也可单独导出。
- 导出位于 `.local-data/exports/`，合并前快照位于 `.local-data/record-backups/`。请将重要导出另存到其他设备。
- 导入先预览：完全重复项跳过；冲突项逐条选择保留本地、替换或保留两条等可用动作，确认后才合并，不自动写入输入法。
- 删除未同步的新增项会直接移除；删除已写入项先标记待删除，同步成功后同时清理本地记录及受管表。
- “从输入法找回”只读取本工具生成的表，不扫描全部学习词库。新表配套管理清单可保留分类；旧表无法确认分类时默认快捷短语，需在预览中校对。
- 历史备份是还原点，删除当前记录不会改写历史备份；恢复旧备份可能找回曾删除的记录。

### 中断恢复与输入法更新

- 写入前保存并校验备份，记录操作阶段，文件采用刷盘后原子替换；同步或恢复期间禁止并发修改。
- 再启动发现未完成操作时暂停修改，提示手动恢复到操作前。恢复失败保留现场和备份，不继续写入。
- 每次同步前重新检测路径与方案；用户目录变化必须确认，失效方案的记录保留，但需调整后才能同步。
- 这不是对所有未来输入法版本的兼容承诺；部署后验证生成配置，仍需实际试输。
- 软件恢复不能抵御磁盘损坏、存储硬件不兑现刷盘或整个目录丢失，重要记录仍需异地备份。

### 操作记录

操作日志保留最近30天、最多1000条，启动和新增日志时自动清理。页面显示最近100条（相关操作合并展示），诊断导出包含全部保留日志。此规则不清理词条、配置备份或中断恢复状态文件。

常规列表只显示时间、模块、动作和结果。点击带箭头的记录可查看：

- 新增、修改和删除数量；
- 目标输入方案；
- 自动备份编号；
- 执行耗时与过程；
- 失败原因和处理建议。

升级前产生的旧日志没有保存这些字段，界面会明确标记为基础记录，不会推测或伪造缺失信息。

## 数据与隐私

运行数据保存在：

```text
app/.local-data/
```

其中可能包含草稿正文、操作事件和配置备份。该目录已写入 `.gitignore`，不得提交、打包或上传。仓库不包含任何用户词库、个人快捷短语、本机日志、配置备份、Windows 用户名或本机绝对路径。

详细说明请参阅 [PRIVACY.md](PRIVACY.md)。

## 安全机制

- 路径自动识别失败时停止写入。
- 不覆盖不属于本工具管理的自定义配置或短语文件。
- 写入采用临时文件后原子替换。
- 使用锁文件避免并发写入和恢复。
- 备份恢复前校验清单与 SHA-256。
- 写入或恢复失败时尝试还原原文件并重新部署。
- 页面日志不包含词语正文、完整路径和异常堆栈。

安全问题请参阅 [SECURITY.md](SECURITY.md)。

## 测试状态

当前自动化测试覆盖：

- 草稿新增、修改、重复校验和删除状态；
- 部署状态追踪和日志字段脱敏；
- 多方案短语表生成；
- 写入前备份和失败回滚；
- 外部配置冲突保护；
- 备份校验、恢复、固定和自动清理。

自动化测试不能代替真实小狼毫试输。发布前仍需在 Windows 上完成拼音、五笔和五笔拼音方案的实际输入验收。

## 已知限制

- 当前便携版通过本地服务和默认浏览器运行，尚未提供代码签名、自动更新或原生单窗口外壳。
- 当前写入的是工具管理的固定短语表，不直接编辑 Rime 的活跃用户学习数据库。
- 已有同名且不归本工具管理的 `.custom.yaml` 或短语表时，工具会停止操作，需要用户自行处理冲突。
- 输入方案的实际行为取决于对应 Rime 方案及过滤链，部署成功不等于所有候选表现都符合预期。
